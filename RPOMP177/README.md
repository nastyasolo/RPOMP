# Мультимедиа — камера, видеоплеер, галерея

Многооконное приложение с камерой, встроенным видеоплеером и галереей 
сохранённых фото.

## Функционал
- Съёмка фото через камеру устройства (Camera2 API), сохранение 
  в /Pictures/MediaApp/
- Видеоплеер с перемоткой и управлением
- Галерея сохранённых фото с навигацией и масштабированием
- Экран справки

## Стек
Java · Android SDK · Camera2 API · MediaPlayer · RecyclerView · SQLite
