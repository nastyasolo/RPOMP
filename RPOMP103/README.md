# MyNotes — CRUD-заметки на SQLite

Приложение для управления заметками на четырёх вкладках ViewPager: 
просмотр, добавление, удаление, обновление.

## Функционал
- 4 вкладки: Show / Add / Del / Update
- Поиск по названию, сортировка по ID и алфавиту
- Кастомный ListView-адаптер
- Все операции поверх SQLite

## Стек
Java · Android SDK · SQLiteOpenHelper · FragmentPagerAdapter · 
ListView + CursorAdapter
