# Медиаплеер — выбор и воспроизведение файлов

Приложение для выбора файла из внешнего хранилища и его обработки 
в зависимости от типа.

## Функционал
- Изображение → отображение в ImageView
- Аудио → воспроизведение через MediaPlayer
- Видео → воспроизведение через VideoView
- Управление: play / pause / stop, изменение скорости
- SeekBar для перемотки, кнопка сброса

## Стек
Java · Android SDK · MediaPlayer · VideoView · SeekBar · 
Intent.ACTION_GET_CONTENT
