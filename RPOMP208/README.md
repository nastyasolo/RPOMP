# Геолокация — карта и маршрут

Приложение для отображения карты с текущим местоположением, 
маркерами и построением маршрута.

## Функционал
- Карта с текущим местоположением пользователя
- Добавление маркеров, построение маршрута
- Отображение координат, статуса GPS, пройденного расстояния
- Сохранение маршрута и маркеров между запусками

## Стек
Java · Android SDK · osmdroid · Google Play Services Location · 
SharedPreferences
