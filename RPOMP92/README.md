# MiniShop — список товаров и корзина

Приложение из двух Activity: список товаров с чекбоксами и корзина 
с выбранными позициями.

## Функционал
- Кастомный список товаров (иконка, ID, название, стоимость, чекбокс)
- Счётчик выбранных товаров в футере
- Переход в корзину с выбранными товарами
- Передача данных между Activity через Parcelable

## Стек
Java · Android SDK · ListView · BaseAdapter · Parcelable
